# 🏋️ Fitness Club Site

Современное одностраничное веб-приложение (SPA) для фитнес-клуба, разработанное на **HTML5, CSS3 и JavaScript** без использования сторонних фреймворков.

Проект предоставляет пользователям информацию о фитнес-клубе, тренерах, расписании занятий и тарифах, а также позволяет оставлять заявки на посещение клуба и персональные тренировки.

## 📖 Описание проекта

Fitness Club Site — это клиентское веб-приложение для фитнес-клуба, реализованное по принципу Single Page Application (SPA).

### Основные возможности

✅ Просмотр информации о фитнес-клубе

✅ Просмотр расписания тренировок

✅ Просмотр информации о тренерах

✅ Просмотр тарифных планов

✅ Регистрация заявок на тренировки

✅ Авторизация пользователей

✅ Административная панель

✅ Хранение данных через LocalStorage

---

## 🛠 Используемые технологии

| Технология       | Назначение                  |
| ---------------- | --------------------------- |
| HTML5            | Разметка страниц            |
| CSS3             | Оформление интерфейса       |
| JavaScript ES6+  | Логика приложения           |
| LocalStorage API | Хранение данных             |
| Hash Routing     | Навигация между страницами  |

# 📦 Описание модулей

## 📄 index.html

Главный файл приложения.

### Отвечает за:

* структуру сайта;
* подключение стилей;
* подключение JavaScript-модулей;
* подключение шрифтов и сторонних библиотек;
* отображение всех страниц приложения.

---

## 🎨 css/reset.css

Файл сброса стандартных браузерных стилей.

### Назначение

* устранение различий между браузерами;
* создание единой основы для стилизации интерфейса.

---

## 🎨 css/main.css

Основной файл оформления проекта.

### Отвечает за

* адаптивную верстку;
* стили меню;
* карточки тренеров;
* оформление расписания;
* кнопки и формы;
* модальные окна;
* административную панель;
* анимации интерфейса.

---

## 📊 js/data.js

Модуль хранения данных приложения.

### Содержит:

### Абонементы

Массив данных о тарифных планах:

* название тарифа;
* стоимость;
* длительность действия.

### Расписание

Информация о тренировках:

* день недели;
* время;
* вид тренировки;
* тренер.

### Тренеры

Информация о сотрудниках клуба:

* имя;
* фамилия;
* специализация;
* опыт работы;
* образование;
* фотография.

### Пользователи

Данные для авторизации и разграничения доступа.

Поддерживаются роли:

* Administrator
* User

---

## 🧭 js/router.js

Модуль маршрутизации SPA-приложения.

### Основные задачи

* управление навигацией;
* обработка URL-маршрутов;
* отображение нужных страниц;
* контроль доступа к административному разделу;
* обновление состояния меню.

### Основные функции

#### initRouter()

Инициализация маршрутизатора.

#### handleRoute()

Определение текущего маршрута.

#### renderPage()

Отображение выбранной страницы.

---

## ⚙️ js/app.js

Главный модуль приложения.

Является центральной точкой запуска всей системы.

### Выполняет

#### Инициализацию приложения

* запуск маршрутизатора;
* восстановление данных пользователя;
* загрузку сохраненных заявок.

#### Управление состоянием

Содержит объект состояния приложения:

```javascript
state = {
  currentUser,
  requests,
  currentPage,
  selectedTrainer
}
```

#### Авторизацию пользователей

* вход в систему;
* выход из системы;
* проверка ролей;
* защита административной панели.

#### Работу с заявками

* создание заявки;
* изменение заявки;
* удаление заявки;
* просмотр заявок администратором.

#### Работу с тренерами

* просмотр информации;
* запись на персональные тренировки.

#### Управление интерфейсом

* слайдер;
* меню навигации;
* модальные окна;
* формы;
* карточки тренеров.

# 🏗 Архитектура приложения

Проект построен по модульному принципу.

```text
┌─────────────┐
│ index.html  │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  app.js     │
└──────┬──────┘
       │
 ┌─────┼─────┐
 ▼     ▼     ▼
data  router UI
```

### Взаимодействие модулей

1. `index.html` загружает приложение.
2. `app.js` запускает основную логику.
3. `router.js` управляет навигацией.
4. `data.js` предоставляет данные для отображения.
5. Пользователь взаимодействует с интерфейсом через браузер.

# 💾 Хранение данных

Для сохранения информации используется браузерное хранилище **LocalStorage**.

Сохраняются:

* данные текущего пользователя;
* заявки клиентов;
* настройки интерфейса.

Преимущество такого подхода заключается в сохранении данных между перезагрузками страницы без необходимости использования сервера.

# 🚀 Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/andrewgeek1/fitnessClub-site.git
```

### 2. Перейти в папку проекта

```bash
cd fitnessClub-site
```

### 3. Запустить проект

Можно открыть файл:

```text
index.html
```

или поднять локальный сервер:

```bash
python -m http.server 8000
```

После запуска открыть в браузере:

```text
http://localhost:8000
```
